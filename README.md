# MetaBridge

Translates open-source code repositories into multiple programming languages with customizable syntax highlighting.

MetaBridge is built to be simple and practical, focusing on doing one thing well.

**Why MetaBridge?**

- Translates open-source code repositories into

- syntax highlighting

## Technology Stack

- php
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaBridge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
